ウホーイのテイストで絵を描きます。

## なぜこのスキルがあるか

ウホーイの絵は、ルールがはっきりしています。

https://github.com/uhooi/UhooiPicBook-Icons

このリポジトリのアイコン 38 枚を調べたところ、線の太さ・色・形の崩し方に一貫した決まりがありました。
その決まりをそのまま書き出したのがこのスキルです。守ればテイストが揃います。

絵を生成するツールは使いません。**SVG を書いて PNG に書き出します。** そのほうが線の太さと色を正確に守れます。

## 描き方の流れ

1. 何を描くか決める。曖昧なら描き始める前に聞く
2. `references/palette.md` から色を選ぶ
3. `assets/example.svg` を下敷きに SVG を書く。仕上がりの見本は `assets/example.png` を Read で見る
4. PNG に書き出す
5. **書き出した PNG を Read で開いて自分の目で見る**。直して 3 に戻る
6. 保存先のパスを伝える

5 を飛ばさないでください。SVG のコードを読んだだけでは、絵になっているかわかりません。

## 画風のルール

### 線

- **色は `#000000` だけ**。他の色で輪郭を引かない
- **太さは一定**。1024px のキャンバスで `stroke-width="18"`。パーツごとに変えない
- `stroke-linecap="round"` と `stroke-linejoin="round"` を付ける。角を尖らせない
- 線の設定は `<g>` に 1 回だけ書く。個々の `<path>` で上書きしない

細い線を使ってよいのは、ひげ・しわ・模様など、輪郭ではない細部だけです。そこは 12〜13px にします。

やらないこと。

- 輪郭を黒以外にする
- 部位ごとに太さを変えてメリハリを付ける
- 点線・破線にする
- `opacity` で薄くする

### 色

`references/palette.md` の色だけを使います。ウホーイが実際に使った色を抽出したもので、すべて [HUE/360](https://www.hue360.me/) から選ばれた色です。

表にない色が必要なときだけ HUE/360 で選び直してください。目分量で作った色は使いません。

- ベタ塗りだけ。グラデーション・影・ハイライト・テクスチャは使わない
- 1 体に使う色は 2〜4 色
- 濃淡は、同じ色相の明るさ違いで作る

### 形

**いちばん外しやすいところです。きれいに描くと失敗します。**

本物はペンで手描きしたものなので、線がガタつき、形がいびつです。

- まん丸・真っ直ぐ・左右対称を避ける
- 左右の耳は大きさと角度を変える。脚は 1 本ずつ太さと長さを変える
- 後述のゆらぎフィルタを必ずかける
- 顔のパーツも少しずらす。左右の目を同じ大きさにしない

### 構図

- 1024 × 1024 の正方形、背景は透過
- キャラを画面いっぱいに置く。余白は 1 割まで
- 正面か真横。奥行き・パース・遠近法は使わない
- 影を落とさない。地面も描かない

## SVG の書き方

### ゆらぎフィルタ（必須）

これがないと CG くさくなり、テイストが出ません。

```xml
<defs>
  <filter id="wobble" x="-15%" y="-15%" width="130%" height="130%">
    <feTurbulence type="fractalNoise" baseFrequency="0.012" numOctaves="3" seed="7" result="n"/>
    <feDisplacementMap in="SourceGraphic" in2="n" scale="14"
                       xChannelSelector="R" yChannelSelector="G"/>
  </filter>
</defs>
```

絵全体を包む `<g>` に `filter="url(#wobble)"` を付けます。

- `scale` は 10〜16。これより上げると線の太さが崩れます
- `seed` を変えるとゆらぎ方が変わります。同じ絵で気に入らなければここを変えて描き直します
- `baseFrequency` は 0.01〜0.015。上げると細かく震え、下げるとゆるく波打ちます

### 棒状のパーツは二重線で描く

脚・しっぽ・腕・触角のような細長いパーツは、閉じたパスで囲まずに、**太い黒線の上に細い色の線を重ねて**作ります。

```xml
<path d="M 655 640 L 668 880" stroke-width="80"/>
<path d="M 655 640 L 668 880" stroke="#6EB7DB" stroke-width="44"/>
```

**2 本の差を必ず 36 にします。** 差 36 なら輪郭が両側に 18px ずつ出て、他のパーツと太さが揃います。
差を間違えると、そこだけ輪郭の太さが変わって目立ちます。

太さ自体は 1 本ずつ変えて構いません（60/24、80/44 など）。差だけ守ります。

### 顔

- 目は、白目を `#FFFFFF` で塗って輪郭を引き、瞳を黒ベタの円で置く
- 瞳を白目の中心からずらすと表情が出る
- 鼻は小さい黒の三角か点
- 口は小さく。開けるならパレットの赤かピンクで中を塗る
- まつげを描くなら、短い直線を 3〜5 本
- 白目の輪郭を細くしない。ここも 18px

### 重なり順

奥から手前へ、この順に書きます。後に書いたものが上に乗ります。

しっぽ → 脚 → 体 → 耳 → 頭 → 顔のパーツ

頭は体の後に書いて、体の輪郭線を隠します。

## 書き出し

`rsvg-convert` を使います。

```bash
rsvg-convert -w 1024 -h 1024 uhooi-cat.svg -o uhooi-cat.png
```

背景が透過なので、確認するときは白を敷きます。

```bash
magick uhooi-cat.png -background white -alpha remove -alpha off check.png
```

Slack のカスタム絵文字にするなら 128px も書き出します。

```bash
rsvg-convert -w 128 -h 128 uhooi-cat.svg -o uhooi-cat-128.png
```

保存先は、指定がなければカレントディレクトリです。
ファイル名は内容がわかる英小文字ケバブケースにします（例: `blue-cat.svg`、`kinoko-monster.svg`）。

## 確認

書き出した PNG を必ず Read で開いて見ます。

本物のアイコンを 1 枚横に並べると、ずれに気づきやすいです（本物の入手方法は後述）。

```bash
magick montage check.png UhooiPicBook-Icons/icons/conycat/conycat.png \
  -background white -alpha remove -alpha off -tile 2x1 -geometry 460x460+6+6 compare.png
```

見るところ。

- 整いすぎていないか（いちばんよくある失敗）
- 輪郭の太さがどこも同じに見えるか
- パーツが浮いていないか、線が途切れていないか
- 顔が中央に寄りすぎて余白が空いていないか

## 迷ったら本物を見る

テイストが合っているか自信が持てないときは、本物を並べて見比べます。

```bash
git clone --depth 1 https://github.com/uhooi/UhooiPicBook-Icons.git
magick montage UhooiPicBook-Icons/icons/*/*.png -background white \
  -alpha remove -alpha off -tile 5x8 -geometry 200x200+6+6 sheet.png
```

書き出した `sheet.png` を Read で開くと、38 体の作例が一覧で見られます。
描くものに近いキャラを 1 体選んで、自分の絵と 2 枚並べて比べると、ずれがはっきりします。

## セルフチェック

- [ ] 輪郭の色が `#000000` だけになっている
- [ ] `stroke-width` が 18 で統一されている（細部の 12〜13px を除く）
- [ ] 二重線のパーツすべてで、黒と色の差が 36 になっている
- [ ] `stroke-linecap` と `stroke-linejoin` が `round` になっている
- [ ] 使った色がすべて `references/palette.md` にある
- [ ] グラデーション・影・半透明を使っていない
- [ ] ゆらぎフィルタがかかっている
- [ ] 左右対称になっていない
- [ ] 背景が透過になっている
- [ ] キャラが画面いっぱいに入っている
- [ ] **書き出した PNG を自分の目で見た**

最後に、保存先のパスと、使った色を伝えます。
